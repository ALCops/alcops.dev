## Contributing

ALCops is built by the Business Central community and every contribution matters, whether it is a new rule, a bug fix, a documentation improvement or just sharing an idea. No contribution is too small.

- [ALCops/Analyzers](https://github.com/ALCops/Analyzers) — analyzer code and tests
- [ALCops/alcops.dev](https://github.com/ALCops/alcops.dev) — documentation and rule pages
- [Discussions](https://github.com/ALCops/Analyzers/discussions) — the best place to start if you are unsure where something belongs
