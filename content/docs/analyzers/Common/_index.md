Cross-cutting diagnostics from the shared `ALCops.Common` library. `ALCops.Common.dll` is loaded alongside every cop (it is part of every documented setup), so these diagnostics are reported once regardless of which cops you enable.

## Rules

| ID | Title | Severity | Enabled | Code Fix |
|---|---|---|---|---|
| [CM0001](cm0001/) | The ALCops configuration file could not be fully loaded | Warning | ✓ | |
