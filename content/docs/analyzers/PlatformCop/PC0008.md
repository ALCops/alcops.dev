[`SetFilter`](https://learn.microsoft.com/dynamics365/business-central/dev-itpro/developer/methods-auto/record/record-setfilter-method) supports placeholder substitution (`%1`, `%2`, ...) in its filter expression. However, when the filter string also contains a `*`, `?`, or `@` operator, the placeholder is not substituted. The literal text `%1` becomes part of the filter, and the query silently returns the wrong records or none at all.

Wrap the filter expression in `StrSubstNo()` to resolve placeholders before passing the result to `SetFilter`.

### Example

{{< highlight al "hl_lines=5" >}}
procedure FindCustomerByVAT(VATNo: Text)
var
    Customer: Record Customer;
begin
    Customer.SetFilter("VAT Registration No.", '*%1*', VATNo); // Avoid unsupported operators with placeholders in SetFilter expressions [PC0008]
end;
{{< /highlight >}}

Use `StrSubstNo()` to substitute the placeholder first:

{{< highlight al "hl_lines=5" >}}
procedure FindCustomerByVAT(VATNo: Text)
var
    Customer: Record Customer;
begin
    Customer.SetFilter("VAT Registration No.", StrSubstNo('*%1*', VATNo));
end;
{{< /highlight >}}
