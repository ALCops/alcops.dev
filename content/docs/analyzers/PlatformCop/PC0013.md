+++
title = 'Record.Get procedure arguments (PC0013)'
linkTitle = 'PC0013'
+++

The Record.Get method requires arguments that match the primary key fields of the table. Passing incorrect or mismatched arguments will result in runtime errors or incorrect record retrieval.

### Example

The following code passes incorrect arguments to Get:

```al
codeunit 50100 MyCodeunit
{
    procedure GetSalesLine()
    var
        SalesLine: Record "Sales Line";
    begin
        SalesLine.Get('1001'); // Record.Get procedure arguments [PC0013] - missing Line No.
    end;
}
```

To fix this, pass all primary key field values:

```al
codeunit 50100 MyCodeunit
{
    procedure GetSalesLine()
    var
        SalesLine: Record "Sales Line";
    begin
        SalesLine.Get(SalesLine."Document Type"::Order, '1001', 10000);
    end;
}
```
