AC0037 checks the app's `publisher` against a configured regular-expression convention. It is disabled by default because publisher naming is an organization-specific convention.

### Configure the pattern

Add an `AllowPattern`, a `DisallowPattern`, or both under `Manifest.Publisher` in `alcops.json`:

{{< highlight json >}}
{
    "Manifest": {
        "Publisher": {
            "AllowPattern": "^Contoso Ltd\\.$"
        }
    }
}
{{< /highlight >}}

Patterns use .NET regular-expression syntax. `AllowPattern` requires a match; `DisallowPattern` reports a match. Anchor patterns with `^` and `$` when the entire publisher value must match.

The rule does not check for a missing publisher when no pattern is configured. `publisher` is a required app manifest property, so manifest validation already handles its absence.

### Enable the rule

Add AC0037 to the project's `.ruleset.json`:

{{< highlight json >}}
{
    "name": "My Project Ruleset",
    "rules": [
        {
            "id": "AC0037",
            "action": "Info"
        }
    ]
}
{{< /highlight >}}

### When the diagnostic is reported

AC0037 reports on `publisher` when a configured pattern is invalid or times out, the value does not match `AllowPattern`, or it matches `DisallowPattern`. No diagnostic is reported when neither pattern is configured.
