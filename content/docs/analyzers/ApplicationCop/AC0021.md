The `Tok` suffix is a naming convention that marks a label as a token — a hardcoded, non-translatable value. A locked label without the suffix looks translatable at a glance. During refactoring, someone may remove `Locked = true` without realizing the label holds a technical value, and its companion rule [AC0020](../ac0020/) will not catch the mistake because the name lacks the `Tok` marker.

Append `Tok` to the label name.

### Example

{{< highlight al "hl_lines=4" >}}
codeunit 50100 MyCodeunit
{
    var
        ApiVersion: Label 'v1.0', Locked = true; // Locked Label must have a suffix Tok [AC0021]
}
{{< /highlight >}}

To fix this, append `Tok` to the label name:

{{< highlight al "hl_lines=4" >}}
codeunit 50100 MyCodeunit
{
    var
        ApiVersionTok: Label 'v1.0', Locked = true;
}
{{< /highlight >}}
