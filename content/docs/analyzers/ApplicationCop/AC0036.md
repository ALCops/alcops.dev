An `action` with `RunObject = Page X` or `RunObject = Report X` uses the target's `Caption`, `ToolTip`, `AboutTitle` and `AboutText` for each of these properties it does not set itself. The compiler does not copy the text: it writes a reference to the target's property into the action's metadata, and the client shows the target's translated value.

> With runtime version 18.0, the `ToolTip` property can be set at the page object level. When a navigation action has `RunObject = page X` and the target page has a `ToolTip` set, the action inherits the page's tooltip if no tooltip is explicitly specified on the action itself. This mirrors the existing behavior for reports.

— [ToolTip Property](https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/developer/properties/devenv-tooltip-property) on Microsoft Learn

An action that repeats the target's value is translated twice. The XLIFF file gets a trans-unit for the action, noted as `Page Sales Overview - Action Customers - Property Caption`, next to the one for the target, `Page Customer List - Property Caption`. Both trans-unit ids end in `Property 2879900` and both carry `Customers` as their source. When a translator updates only the page caption, the action keeps the old translation and the menu shows a different word than the page it opens. Remove the property from the action and let it inherit the target's value.

### Example

{{< highlight al "hl_lines=16-17" >}}
page 50101 "Customer List"
{
    Caption = 'Customers';
    ToolTip = 'View and edit customers.';
    // ...
}

page 50100 "Sales Overview"
{
    actions
    {
        area(Processing)
        {
            action(Customers)
            {
                Caption = 'Customers'; // The Caption of action 'Customers' has the same value as the Caption of its RunObject page 'Customer List' and can be removed [AC0036]
                ToolTip = 'View and edit customers.'; // The ToolTip of action 'Customers' has the same value as the ToolTip of its RunObject page 'Customer List' and can be removed [AC0036]
                ApplicationArea = All;
                Image = Customer;
                RunObject = Page "Customer List";
            }
        }
    }
}
{{< /highlight >}}

Remove the duplicated properties. Through `RunObject` the action shows the page's caption and tooltip:

{{< highlight al "hl_lines=11" >}}
page 50100 "Sales Overview"
{
    actions
    {
        area(Processing)
        {
            action(Customers)
            {
                ApplicationArea = All;
                Image = Customer;
                RunObject = Page "Customer List";
            }
        }
    }
}
{{< /highlight >}}

### When the diagnostic is reported

- The app's `runtime` in `app.json` is 18.0 (Business Central 2026 release wave 2) or higher. The rule is gated on that release as a whole: on a lower runtime nothing is reported, including `Caption` duplicates.
- The action is a plain `action` with a `RunObject` that points to a page or a report.
- The action's `Caption`, `ToolTip`, `AboutTitle` or `AboutText` has the same text as the same property of the target. A report target's `Caption` and `ToolTip` come from the report object; its `AboutTitle` and `AboutText` come from its `requestpage`.
- The diagnostic is reported on the action's property, once for every duplicated property.
- A `modify(ActionName)` block in a page extension is reported when the base action has a page or report `RunObject`, does not set the property itself, and the `modify` sets the same text as the target.
- The comparison is case-sensitive and looks at the text only: `Locked`, `Comment` and `MaxLength` are ignored.

### Exception

The rule does not compare a property when either side uses its multilanguage variant (`CaptionML`, `ToolTipML`, `AboutTitleML`, `AboutTextML`). Obsolete actions and obsolete targets, groups, `actionref`s, other action kinds, codeunit, query and xmlport targets, and page customizations are not reported. The `AboutTitle` and `AboutText` of a report from a dependency's symbol package are not compared, because its request page is not visible to the analyzer.

Neither [AC0011](../ac0011/), which requires a caption on actions, nor Microsoft's [CodeCop AA0218](https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/developer/analyzers/codecop-aa0218), which requires a tooltip on page actions, accounts yet for the value an action inherits from `RunObject`. Removing the action's `Caption` or `ToolTip` can trigger one of them. Until they do, keep the copy deliberately and suppress AC0036 on that line:

{{< highlight al >}}
action(Customers)
{
    // Keep the ToolTip until the ToolTip-required cops accept the value inherited from RunObject.
#pragma warning disable AC0036
    ToolTip = 'View and edit customers.';
#pragma warning restore AC0036
    ApplicationArea = All;
    RunObject = Page "Customer List";
}
{{< /highlight >}}
