+++
title = 'FlowFields should not be editable (AC0001)'
+++

Any Flowfield should be set to `Editable = false`. If the property is not present or set to `True` a warning will occur.

```AL
field(1; MyField; Integer) // FlowFields should not be editable. [AC0001]
{
    FieldClass = FlowField;
}
```

```AL
field(1; MyField; Integer)
{
    Editable = false;
    FieldClass = FlowField;
}
```

### Exception
Use a [pragma directive](https://learn.microsoft.com/en-us/dynamics365/business-central/dev-itpro/developer/directives/devenv-directive-pragma) to suppress the diagnostic, where it's best pratice to add a comment justifying this deviant behavior.
```AL
#pragma warning disable AC0001 // FlowField needs to be editable because ...
field(1; MyField; Integer)
{
    FieldClass = FlowField;
}
#pragma warning restore AC0001
```
