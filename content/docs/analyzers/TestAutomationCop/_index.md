The TestAutomationCop applies exclusively to AL test automation. It validates the structure and correctness of test code, ensuring proper use of test attributes and patterns.

## Rules

| ID | Title | Severity | Enabled | Code Fix |
|:---|:------|:---------|:--------|:---------|
| [TA0001](ta0001/) | Global procedures in test codeunits must be test methods | Warning | Yes | No |
